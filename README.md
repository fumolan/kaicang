# 📈 开仓

> 赢时赚多 · 输时亏少 — 加密货币交易分析台

**在线使用**: https://fumolan.github.io/kaicang/

## 功能

- **30 币池**: 币安 + OKX 双所共上线币种, 按双所流动性精选
- **开仓扫描 (S 键)**: 一键扫描 30 币四信号得分, 排名找出可开仓的币
- **分币种策略**: 主流/山寨/高波动三档, 各自的信号权重、阈值、止盈止损
- **信号共振**: 买盘主导 · 鲸鱼方向 · 量价配合 · 近支撑/阻力 四信号评分
- **盘口大墙**: 真实墙/假墙识别, 持续时间 + 被吃/撤单追踪
- **成交透视**: 量价分布 · 交易者画像(谁在买卖) · 市场共识
- **回测 + 模拟交易**: 策略仓 vs 冲动仓对比, 止盈止损爆仓全流程, 量化"冲动的代价"
- **双数据源**: 币安 / OKX 一键切换

## 说明

- 纯静态页面, 数据实时来自交易所公开 API, 无需注册登录
- 每位访客的交易记录保存在**自己的浏览器**里(localStorage), 互不可见
- 交易记录可导出 md 文件(浏览器下载; 本地跑 `python3 server.py` 版可直写文件夹)
- 仅供学习研究, 不构成投资建议
